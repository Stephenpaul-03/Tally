# README screenshots

Captured on 18 October 2026 at 1080 × 2400 in an isolated Android emulator running Tally's Expo development client with the current Metro bundle. The Ocean accent and dark theme are ordinary app settings. Developer menus, debug overlays and notifications are hidden for capture.

The workspace is disposable. Its transactions come from Tally's built-in three-month sample-data generator, available through Settings → About → tap Version seven times → Developer tools. No personal transactions or account details are included. Sample descriptions and amounts follow the category name: milk purchases stay under Milk & Dairy, rent is charged once per month, and rental receipts stay under Rental Income.

The PNGs are direct emulator screen captures. They are not mockups and have no edited app content. The status bar uses Android demo mode for a consistent 9:41 clock and battery display.

To refresh them, start a development build with `npm run android`, complete onboarding in a disposable workspace, load sample data, dismiss the tour and development menus, and capture the Home, Transactions, Insights, Categories, Appearance, welcome and yearly-overview screens. Save the seven PNGs under the existing names so the README links continue to work.
