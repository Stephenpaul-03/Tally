# Reporting a vulnerability

Please report vulnerabilities privately rather than posting exploit details in a public issue. If private vulnerability reporting is enabled for the repository, use **Security → Report a vulnerability**. Otherwise, contact the maintainer through the contact information on their GitHub profile to arrange a private report.

Include the affected version or commit, reproduction steps, impact, and a minimal example using fake data. Do not send personal finance databases, backup passwords, signing credentials, or access tokens.

General UI bugs and feature requests belong in the issue tracker. This policy does not promise a response time or security support for a particular version.
